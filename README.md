# 🌈 ROBALL — 2D футбол для Roblox Studio

2D-футбол 1 на 1 против компьютера. Вся игра — в одном скрипте, карту строить не надо.

## 📂 Части игры

| Часть | Файл | Что внутри |
|-------|------|------------|
| 1 (v1.3) | [`Football_2D_Part1.txt`](Football_2D_Part1.txt) | Радужное лобби **ROBALL** без поля, кнопка «ИГРАТЬ 1 на 1», выбор сложности бота, настройки камеры «ВСЁ ПОЛЕ / ТОЛЬКО Я», большое 2D-поле, плавная физика круглых фишек, тяжёлый объёмный мяч, чистый удар по линии контакта фишки и мяча без влияния курсора, атакующий бот с прессингом и анти-застреванием в углах, новая графика футболиста и робота, 7-секундный замедленный повтор каждого гола, отсчёт 3-2-1 перед матчем и после каждого гола, матч до 3 голов, таймер 2:00, тихие звуки и аплодисменты при голе |

## 📥 Как запустить (часть 1)

1. Открой Roblox Studio (подойдёт пустая **Baseplate**).
2. В **Explorer** найди папку **StarterGui**.
3. Наведи на неё мышь → **[+]** → **LocalScript**.
4. Удали в открывшемся скрипте всё (`print("Hello world!")`).
5. Открой файл `Football_2D_Part1.txt`, скопируй **весь код целиком** и вставь в LocalScript.
6. Нажми **Play (▶)**. Играть!

> Если обновляешь старую версию: **не создавай второй LocalScript**. Открой тот же LocalScript, удали весь старый код и вставь новый файл целиком.

Больше ничего создавать не нужно: скрипт сам строит лобби, поле, фишки и мяч. В лобби поля нет — матч появляется только после выбора сложности и кнопки «ИГРАТЬ».

## 🎮 Управление

- **WASD / стрелки** — движение фишки
- **ЛКМ (клик или держать)** — чистый физический удар при касании: мяч летит строго от центра твоей фишки через центр мяча. Курсор на направление удара не влияет. Держание заряжает силу
- **ЛКМ вдали от мяча** — короткий рывок к курсору
- **Shift** — спринт
- **Пробел** — во время игры быстрый физический удар; во время повтора гола — пропустить повтор
- **P / ⏸** — пауза
- **Кнопка «ВИД» в матче или настройки в лобби** — всё поле либо крупный план за игроком
- **Телефон** — веди фишку пальцем по полю, кнопка **«УДАР»**

Твои ворота — **слева** (синяя фишка «ВЫ»), ворота бота — **справа**.
Матч идёт до **3 голов** и длится **2 минуты**; при ничьей по истечении времени — **золотой гол**.
После каждого гола показывается **7-секундный замедленный повтор** (последние 3,5 секунды игры в два раза медленнее). Затем все возвращаются на места и идёт отсчёт **3-2-1**.

## 🤖 Сгенерированная фотка бота (необязательно)

В репозитории лежит [`assets/bot_face.png`](assets/bot_face.png) — готовая круглая мордочка робота. Сразу из GitHub Roblox картинку прочитать не может, поэтому по умолчанию в игре уже стоит такая же рисованная мордочка из кода и ничего делать не надо.

Если хочешь именно эту PNG на круге бота:
1. Скачай `assets/bot_face.png`.
2. В Roblox Studio открой **Asset Manager → Images → Add Images** и загрузи файл.
3. Скопируй ID загруженной картинки.
4. В начале скрипта в `CUSTOM_FACE_IMAGES` поставь: `BOT = "rbxassetid://ТВОЙ_ID",`
