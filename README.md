# ⚽ RFC FOOTBALL 2D — игра для Roblox Studio

2D-футбол 1 на 1 против компьютера. Вся игра — в одном скрипте, карту строить не надо.

## 📂 Части игры

| Часть | Файл | Что внутри |
|-------|------|------------|
| 1 | [`Football_2D_Part1.txt`](Football_2D_Part1.txt) | Меню на весь экран, кнопка «ИГРАТЬ 1 на 1», выбор сложности бота, 2D-матч: круглые фишки, мяч в центре, удар на ЛКМ по курсору, ИИ бота, матч до 3 голов, таймер 2:00, пауза, экран конца матча |

## 📥 Как запустить (часть 1)

1. Открой Roblox Studio (подойдёт пустая **Baseplate**).
2. В **Explorer** найди папку **StarterGui**.
3. Наведи на неё мышь → **[+]** → **LocalScript**.
4. Удали в открывшемся скрипте всё (`print("Hello world!")`).
5. Открой файл `Football_2D_Part1.txt`, скопируй **весь код целиком** и вставь в LocalScript.
6. Нажми **Play (▶)**. Играть!

Больше ничего создавать не нужно: скрипт сам строит меню, поле, фишки и мяч.

## 🎮 Управление

- **WASD / стрелки** — движение фишки
- **ЛКМ (держать)** — зарядка удара: прицел + полоса силы
- **ЛКМ (отпустить)** — удар, мяч летит в сторону курсора (вдали от мяча ЛКМ = рывок)
- **Shift** — спринт
- **Пробел** — быстрый удар по воротам бота
- **P / ⏸** — пауза
- **Телефон** — веди фишку пальцем по полю, кнопка **«УДАР»**

Твои ворота — **слева** (синяя фишка «ВЫ»), ворота бота — **справа**.
Матч идёт до **3 голов** и длится **2 минуты**; при ничьей по истечении времени — **золотой гол**.
